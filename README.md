# Screen Market Scraper

Программа для автоматического захвата и анализа скриншотов игрового рынка с использованием компьютерного зрения.

## Описание

При нажатии клавиши **Print Screen** программа:

1. Делает снимок основного монитора
2. Сохраняет изображение в папку `screenshots`
3. Анализирует содержимое с помощью компьютерного зрения
4. Извлекает информацию о товаре и ценах
5. Сохраняет данные в CSV-файл

---

## Быстрый старт

1. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

2. **Создайте файл конфигурации:**
   - Скопируйте `.env.example` в `.env`:
     ```bash
     copy .env.example .env
     ```
   - Откройте `.env` и настройте параметры (путь к Tesseract, горячая клавиша и т.д.)

3. **Запустите программу:**
   ```bash
   python main.py
   ```

Откроется интерактивное меню с выбором действий.

## Интерактивное меню

При запуске `main.py` открывается главное меню:

```
╔═══════════════════════════════════════════════╗
║    Screen Market Scraper — Главное меню       ║
╠═══════════════════════════════════════════════╣
║  → Обработка справочника (item.json)          ║
║    Калибровка изображения (example.png)       ║
║    Установка горячей клавиши                  ║
║    Мониторинг экрана                          ║
║    Выход                                      ║
╚═══════════════════════════════════════════════╝

Стрелки: выбор | Enter: начать | Esc: выход
```

### Пункты меню:

1. **Обработка справочника (item.json)** — запуск скрипта обработки каталога предметов
2. **Калибровка изображения (example.png)** — интерактивная настройка зон распознавания
3. **Установка горячей клавиши** — выбор клавиши или комбинации для захвата скриншота
4. **Мониторинг экрана** — запуск основной программы (ожидание нажатия горячей клавиши)
5. **Выход** — завершение работы программы

## Конфигурация

### Файл .env

Программа использует файл `.env` для настройки параметров:

```env
# Режим отладки (true/false)
DEBUG_MODE=false

# Горячая клавиша для захвата скриншота
HOTKEY=print_screen

# Путь к Tesseract OCR
TESSERACT_PATH=C:\Users\USERNAME\AppData\Local\Programs\Tesseract-OCR\tesseract.exe

# Язык OCR
OCR_LANG=rus+eng

# Папка для скриншотов
SCREENSHOTS_DIR=screenshots

# Файл выходных данных
DATA_FILE=market_data.csv

# Файл конфигурации ROI
ROI_CONFIG_FILE=roi_config.json

# Путь к items.json каталогу
ITEMS_CATALOG_PATH=items.json

# Файл примера для калибровки
EXAMPLE_FILE=example.png
```

## Форматы данных

### Имя файла скриншота

```
YYYY-MM-DD-HH-MM-SS.png
```

**Пример:** `2025-01-15-14-30-45.png`

### Структура данных в market_data.csv

```csv
item_name,sell_price,buy_price,average_price,screenshot_date,item_tier,item_enchantment,item_quality
"Название предмета",100,80,90,2025-01-15T14:30:45,6,1,0
```

| Поле               | Описание                                         |
| ------------------ | ------------------------------------------------ |
| `item_name`        | Название предмета (распознаётся рядом с иконкой) |
| `sell_price`       | Цена продажи (в правой части экрана)             |
| `buy_price`        | Цена покупки (в правой части экрана)             |
| `average_price`    | Средняя цена (в правой части экрана)             |
| `screenshot_date`  | Дата и время создания скриншота (ISO 8601)       |
| `item_tier`        | Тир предмета (0-8), извлекается из справочника   |
| `item_enchantment` | Зачарование предмета (0-4), из справочника       |
| `item_quality`     | Качество предмета (временно 0)                   |

## Блоки для распознавания (по example.png)

Пример файла `example.png` содержит размеченные области для обучения и настройки:

| Цвет блока        | Что содержит      |
| ----------------- | ----------------- |
| 🔵 **Синий**      | Название предмета |
| 🔴 **Красный**    | Цена покупки      |
| 🟢 **Зелёный**    | Цена продажи      |
| 🟣 **Фиолетовый** | Средняя цена      |

Эти зоны используются для калибровки алгоритма компьютерного зрения и настройки областей интереса (ROI — Region of Interest).

## Логика работы

1. **Отслеживание хоткея**  
   Программа работает в фоновом режиме и перехватывает нажатие **Print Screen** на глобальном уровне.

2. **Захват экрана**  
   При срабатывании триггера делается снимок **первого (основного) монитора**.

3. **Сохранение изображения**  
   Файл сохраняется в папку `screenshots/` с именем в формате `YYYY-MM-DD-HH-MM-SS.png`.

4. **Анализ изображения**
   - Загружается скриншот
   - Определяются цветные блоки (или их текстовые аналоги на реальном интерфейсе)
   - С помощью **OCR** распознаётся текст в каждой зоне
   - Данные структурируются и приводятся к нужному формату

5. **Обогащение данными из справочника**
   - По названию предмета выполняется поиск в `items.json`
   - Извлекаются: тир (tier), зачарование (enchantment), качество (quality)
   - Если предмет не найден, используется fallback-парсинг из названия

6. **Сохранение в CSV**
   - Загружается существующий файл `market_data.csv` (если есть)
   - Новая запись с обогащёнными данными добавляется в таблицу
   - Файл сохраняется обратно в корень проекта

## Примеры использования

### Настройка Tesseract OCR

Если Tesseract установлен не по умолчанию, настройте путь в `.env`:

```env
TESSERACT_PATH=C:\Users\USERNAME\AppData\Local\Programs\Tesseract-OCR\tesseract.exe
```

**Проверка поддержки кириллицы:**

```bash
tesseract --list-langs
```

Если `rus` отсутствует, скачайте `rus.traineddata` с https://github.com/tesseract-ocr/tessdata и поместите в папку `tessdata` внутри установки Tesseract.

### Калибровка зон распознавания

1. В главном меню выберите пункт **2. Калибровка изображения (example.png)**
2. Откроется окно с изображением `example.png`
3. Последовательно выделите зоны:
   - 🔵 **title** — название предмета
   - 🔴 **buy_price** — цена покупки
   - 🟢 **sell_price** — цена продажи
   - 🟣 **avg_price** — средняя цена
4. Координаты сохранятся в `roi_config.json`
5. Нажмите `q` для выхода, `u` для отмены выделения

### Установка горячей клавиши

1. В главном меню выберите пункт **3. Установка горячей клавиши**
2. Нажмите желаемую клавишу или комбинацию
3. Горячая клавиша сохранится в `.env`

**Примеры значений:**

- `print_screen` — клавиша PrintScreen
- `alt+enter` — комбинация Alt+Enter
- `f1` — функциональная клавиша

### Запуск мониторинга

1. В главном меню выберите пункт **4. Мониторинг экрана**
2. Программа работает в фоновом режиме
3. Нажмите настроенную горячую клавишу для захвата скриншота
4. Для остановки нажмите `Ctrl+C`

После остановки папка `screenshots/` автоматически очищается.

### Обработка справочника предметов

1. В главном меню выберите пункт **1. Обработка справочника (item.json)**
2. Скрипт обработает `items.json`:
   - Оставит только русские и английские названия
   - Извлечёт тир и зачарование из `UniqueName`
   - Сохранит обработанный файл

---

### Отладка

При включённом `DEBUG_MODE=true` в `.env`:

- В папке `screenshots/` сохраняется `debug_YYYY-MM-DD-HH-MM-SS.png` с наложенными зонами
- В логах отображается распознанный текст из каждой зоны

## Примечания

- Все скриншоты хранятся локально, данные не отправляются на внешние сервера
- При удалении файла `market_data.csv` история данных будет утеряна
- Рекомендуется периодически делать резервные копии CSV-файла
- Файл `example.png` используется как референс для настройки зон распознавания
- Логи автоматически ротируются и хранятся 30 дней
