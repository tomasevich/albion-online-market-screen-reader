# Screen Market Scraper

Программа для автоматического захвата и анализа скриншотов игрового рынка с использованием компьютерного зрения.

## Описание

При нажатии клавиши **Print Screen** программа:
1. Делает снимок основного монитора
2. Сохраняет изображение в папку `screenshots`
3. Анализирует содержимое с помощью компьютерного зрения
4. Извлекает информацию о товаре и ценах
5. Сохраняет данные в JSON-файл

## Форматы данных

### Имя файла скриншота

```
YYYY-MM-DD-HH-MM-SS.png
```

**Пример:** `2025-01-15-14-30-45.png`

### Структура данных в market_data.json

```json
[
  {
    "item_name": "Название предмета",
    "sell_price": 100,
    "buy_price": 80,
    "average_price": 90,
    "tier": "II",
    "screenshot_date": "2025-01-15T14:30:45"
  }
]
```

| Поле | Описание |
|------|----------|
| `item_name` | Название предмета (распознаётся рядом с иконкой) |
| `sell_price` | Цена продажи (в правой части экрана) |
| `buy_price` | Цена покупки (в правой части экрана) |
| `average_price` | Средняя цена (в правой части экрана) |
| `tier` | Тир предмета (римские цифры) |
| `screenshot_date` | Дата и время создания скриншота (ISO 8601) |

## Блоки для распознавания (по example.png)

Пример файла `example.png` содержит размеченные области для обучения и настройки:

| Цвет блока | Что содержит |
|------------|--------------|
| 🔵 **Синий** | Название предмета |
| 🔴 **Красный** | Цена покупки |
| 🟢 **Зелёный** | Цена продажи |
| 🟣 **Фиолетовый** | Средняя цена |
| 🟠 **Оранжевый** | Тир (уровень предмета, римские цифры) |

Эти зоны используются для калибровки алгоритма компьютерного зрения и настройки областей интереса (ROI — Region of Interest).

## Логика работы

1. **Отслеживание хоткея**  
   Программа работает в фоновом режиме и перехватывает нажатие **Print Screen** на глобальном уровне.

2. **Захват экрана**  
   При срабатывании триггера делается снимок **первого (основного) монитора**.

3. **Сохранение изображения**  
   Файл сохраняется в папку `screenshots/` с именем в формате `YYYY-MM-DD-HH-MM-SS.png`.

4. **Анализ изображения**  
   - Загружается скриншот
   - Определяются цветные блоки (или их текстовые аналоги на реальном интерфейсе)
   - С помощью **OCR** распознаётся текст в каждой зоне
   - Данные структурируются и приводятся к нужному формату

5. **Сохранение в JSON**  
   - Загружается существующий файл `market_data.json` (если есть)
   - Новая запись добавляется в массив
   - Файл сохраняется обратно в корень проекта

## Примеры использования

### Запуск программы

```bash
python main.py
```

После запуска программа остаётся в фоновом режиме и ждёт нажатия **Print Screen**.

### Просмотр данных

Откройте `market_data.json` в любом текстовом редакторе или используйте:

```bash
python -m json.tool market_data.json
```

### Анализ истории

Можно написать скрипт для анализа накопленных данных:
- Построение графиков изменения цен
- Поиск товаров с выгодной ценой
- Статистика по тирам предметов

## Требования к окружению

- Python 3.8+
- Доступ к файловой системе (корень проекта и папка `screenshots/`)
- Разрешения на захват экрана (в некоторых ОС)

---

## Примечания

- Все скриншоты хранятся локально, данные не отправляются на внешние сервера
- При удалении файла `market_data.json` история данных будет утеряна
- Рекомендуется периодически делать резервные копии JSON-файла
- Файл `example.png` используется как референс для настройки зон распознавания
